# Ayush Raj | Product Portfolio

My personal portfolio: work experience, product case studies, prototypes, and data projects, plus a way for recruiters and founders to get in touch.

## Tech stack

- **Framework:** React 18, TypeScript, Vite 5
- **Styling:** Tailwind CSS, shadcn/ui (Radix UI)
- **Animation:** Framer Motion
- **Routing:** React Router
- **Hosting:** Vercel
- **Analytics:** Google Analytics 4, Microsoft Clarity, Vercel Speed Insights

## Run locally

```sh
npm install
npm run dev      # http://localhost:8080
npm run build    # production build in dist/
```
